Multi-Agent Tag AI

Unity ML-Agents | C# | Python | 04/25

Description

A reinforcement learning project built in Unity where two AI agents compete in a 1v1 game of tag. One agent is trained to pursue and tag the opposing player while the other learns evasive movement and survival strategies. Using Unity ML-Agents and PPO (Proximal Policy Optimization), the agents improve over time through self-play and reward-based learning.

Contributions

  • Developed a custom reinforcement learning environment in Unity using the ML-Agents toolkit.
  • Designed reward functions and observation systems to encourage intelligent navigation, pursuit, and evasion behavior.
  • Configured and trained agents using PPO, iterating on hyperparameters and reward balancing to improve training stability.
  • Utilized Python training pipelines and TensorBoard analytics to monitor agent learning progress and evaluate performance.
  • Implemented real-time debugging and visualization tools inside Unity to analyze agent decision-making and movement behavior.
  • Researched reinforcement learning concepts independently and leveraged AI-assisted tools to accelerate experimentation and troubleshooting.

Technologies Used

Unity Engine, C#, Python, Unity ML-Agents, PPO Reinforcement Learning, TensorBoard
