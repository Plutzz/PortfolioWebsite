PieTube

Full-Stack Movie Streaming Platform | Django + React

Overview

PieTube is a full-stack web application that allows users to stream public domain movies, manage personalized watchlists, and interact with content through ratings and favorites.

The platform focuses on building a scalable video browsing experience with user authentication, persistent profiles, and cloud-based media storage.

Key Features

  • Stream and browse public domain movies through a responsive web interface
  • User authentication system with personalized profiles
  • Movie rating system with user-specific feedback
  • Favorites and watchlist functionality for personalized content tracking
  • Profile image upload and storage using AWS S3

Technical Implementation

  • Frontend built with React (Vite) for a fast, component-based UI
  • Backend built with Django and Django REST Framework for API development
  • MySQL database used for structured user and movie data storage
  • RESTful API architecture connecting frontend and backend services
  • Session-based authentication for secure user login persistence

Cloud & Deployment

  • Deployed on AWS EC2 with both frontend and backend hosted on a single instance
  • AWS S3 used for storing and serving user profile images
  • Environment-based configuration for secure API keys and database credentials

My Contributions

  • Developed full-stack architecture integrating React frontend with Django REST API
  • Implemented user authentication, session handling, and profile management
  • Designed and built movie rating, favorites, and watchlist systems
  • Configured AWS EC2 deployment and S3 media storage integration
  • Built API endpoints for movie browsing, user interaction, and profile updates
